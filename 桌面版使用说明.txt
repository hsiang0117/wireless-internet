无线网络共享 1.4.2 · 安装测试版

桌面版入口
打开桌面/开始菜单快捷方式或 WirelessInternet.exe，后续操作均在主界面或托盘完成。
本版不提供独立的命令行启动、停止入口；电脑端连接与保护由 C# 后台组件运行，不再使用外部脚本。
界面以 96 DPI 为设计基准，按 Windows 系统 DPI 统一缩放。当前电脑的 150% 系统缩放已实机验证；200% 已提供布局适配，仍需在目标电脑验证。窗口可用空间较小时，可滚动查看内容。
在缩放比例不同的显示器之间移动窗口时，由 Windows 对整个窗口统一缩放，可能出现插值模糊。运行中更改 Windows 缩放倍率后，可从托盘退出并重新打开程序，使界面采用当前系统配置；无需把 Windows 缩放调到 100%。

1.4.2 兼容性修复
修复枚举 VPN/TUN 虚拟网卡时，空路由指标（metric）导致开始连接或保护心跳检查失败的问题。仍校验选定物理 Wi-Fi 与有线网卡的路由指标，不修改 TUN/VPN 的路由规则。
已在当前电脑的 Clash Verge / Mihomo TUN 开启环境中验证连接、断开重连和手机 HTTPS 上网，证书校验通过，保护心跳持续正常。本次实测不代表所有 VPN 均兼容；其他 VPN、驱动与网络组合仍需在目标电脑验证。

安装
1. 在 Windows 10/11 的 x64 电脑运行安装包。目标系统为 Windows 10 2004 及以上，需已启用 .NET Framework 4.8。
2. 默认只为当前用户安装到 %LOCALAPPDATA%\Programs\WirelessInternet，不要求管理员权限，不修改系统 PATH、网卡、路由或手机系统开关。
3. 安装包包含所需 ADB、gnirehtet relay/APK，不需要安装 Android Studio、Java 或开发工具。安装完成时可选择打开程序。
4. 此包没有打包制作者的手机绑定、运行状态、配对码或 ADB 密钥；每台电脑需独立完成首次配置。

手机与电脑前提
手机需提供 Android 11 或更高版本的“无线调试”，并能同时连接 Wi-Fi 和开启自身热点。
并非每个品牌/系统都支持这种组合；只有手机热点、不能开启原生无线调试时，本安装版无法替代该系统限制。
电脑同时需要可用的有线互联网和可连接手机热点的 Wi-Fi 网卡；网卡优先级只检查，不自动修改。
当前基于已验证的 Android 16 环境制作。其他 Windows 电脑、Android 版本与品牌尚未完成实机验收，遇到不支持的状态解析会报错，不承诺所有机型均能使用。

首次配置
1. 电脑先接入有线网络并确认可上网。手机连接可信 Wi-Fi，再同时开启热点；电脑 Wi-Fi 连接手机热点。电脑自身的 Windows 移动热点保持关闭。
2. 手机手动打开“开发者选项 → 无线调试”，按系统提示允许此可信网络。保持手机 Wi-Fi、热点和无线调试开启，全程不需要先插 USB。
3. 打开电脑程序，进入首次配置/“更换/绑定手机”。
4. 手机点“使用配对码配对设备”，将页面里的配对端口与六位配对码填入向导，点击配对。配对页面在此过程中保持打开。
5. 配对成功后回到手机无线调试主页面，把“IP 地址和端口”中的连接端口填入连接验证区。主页面端口与配对端口是不同的，不能混用。
6. 手机主页面可能显示它所连接 Wi-Fi 的地址。电脑通过手机热点访问时，向导会用当前手机热点网关替换地址，保留对应端口，并显示实际连接地址。若电脑有多块 Wi-Fi 网卡，可在高级项指定正确网卡索引。
7. 点击验证/保存。程序会核实选定手机的身份、机主用户、原生无线调试开关，再保存这台电脑自己的绑定。
8. 已在此电脑配对过时，可直接填写主页面连接端口并验证保存，不必重新配对。
配对码只在本次操作中使用，不写日志或配置；ADB 仍按其正常机制在此电脑上保存本机自己的授权凭据。

开始使用
1. 手机 gnirehtet 的“始终开启 VPN”和“阻止未使用 VPN 的连接”均保持关闭。此程序不会操作这些系统开关。
2. 点击“开始连接”。首次会安装随包的 gnirehtet APK；若手机拒绝安装，请按手机提示手动允许，或手动安装 gnirehtet-rust-win64\gnirehtet.apk。
3. 手机出现 VPN 连接请求时手动允许。等待电脑界面显示已连接、保护心跳正常。
4. 手机移动数据可以保持关闭；各应用对网络状态的要求可能因系统而异，需实际检查网页和常用应用。
5. 端口改变时程序优先通过原生 mDNS 重新发现；发现不可用时可在已断开的“更换/绑定手机”中重新填写当前主页面端口。不会固定使用 5555 或自动打开系统无线调试。
6. 本版不支持多个手机同时共享；绑定/运行时会核对指定手机。更换手机前先正常断开并重新配置。

主动更换或重新绑定手机
首次配置完成后，仍可点击主界面右上角“更换/绑定手机”，或托盘菜单同名入口，随时重新打开向导。
1. 若当前还在共享，先点击“断开连接”并等待确认结束。连接中点击更换入口只会提示先断开，不会自动停止共享或修改绑定。
2. 更换时请关闭旧手机的无线调试，避免旧手机被 ADB 自动重连而形成多个真实设备；程序不会删除旧手机的配对记录。
3. 在新手机上准备 Wi-Fi、热点和无线调试，让电脑连接新手机热点，再打开“更换/绑定手机”。
4. 未配对的新手机先完成配对；已在此电脑配对过的手机可直接填写连接端口，检测并保存。
5. 只有新手机验证成功并保存，才替换当前绑定。点击取消、关闭向导或验证失败，都会保留原配置。
6. 保存后点击“开始连接”。本版每次只使用一个绑定；切回旧手机时也可从此入口重新验证保存。

断开、托盘与保护
点击“断开连接”，等到确认已断开，再手动关闭手机无线调试和热点。
窗口右上角 X 只收起到托盘；双击托盘图标恢复。右键菜单可开始、断开和退出；正常“退出”会先自动断开共享。
约 30 秒失联保护沿用电脑监控和手机本地会话守护。短暂断开可尝试恢复，持续失联后结束本次共享。
手机深睡、厂商后台限制或守护进程被终止时，自动退出可能延迟或失效；不能保证所有机型都精确在 30 秒执行。
正常结束优先使用断开/托盘退出。失效 VPN 也可以直接在手机设置中手动断开。

监控与性能
显示中继 TCP/UDP 目标 IP/端口、当前 TCP 连接、VPN 接口流量和网速；流量含协议开销，不代表运营商计费。
日志仅在内存中实时显示，不保存文件。界面最多保留 1500 行、20 万字符，过长单条截断；超出显示处理能力时略过旧消息并提示数量。
日志定时分批绘制；收起、最小化或看连接页时暂停日志文字绘制，网络、统计采样和保护继续运行。
关闭自动滚动后尽量保留阅读位置；超过保留上限的旧内容仍会淘汰。

升级与卸载
先正常断开共享并从托盘退出程序，再运行新版安装包或在 Windows 应用设置中卸载。
安装器不会强杀共享 ADB、模拟器或手机 VPN。发现目标目录仍有运行会话会拒绝继续，请先正常停止。
升级保留此电脑自己的配置。卸载保留无线配置文件，不删除用户全局 .android 凭据，也不从手机删除 APK 或配对记录；这些可按需要在手机和电脑上自行管理。
电脑端连接/断开、网络检查与保护监控均为 C#，安装目录不再包含 PS1/CMD/SH 脚本。support\ConnectionWorker.exe 与 RelayLogHost.exe 是后台组件，请保留。
手机仍需要安卓本地断线守护：其内容已编入 C# 程序，按会话下发到手机，本机临时传输文件随后删除。无需手工保存或运行脚本。
state\ 为本次运行所需的少量状态，运行期间不要手工编辑或删除。安装包不携带任何已有 state。
第三方组件版本与许可证见 notices\ 和对应组件目录。用户不需要 source\ 中的构建工具来运行程序。
