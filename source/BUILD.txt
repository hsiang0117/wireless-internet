WirelessInternet.exe: Program.cs Backend.cs MemoryLog.cs AppForm.cs SetupForm.cs SetupBackend.cs UiDpi.cs
References: System.Windows.Forms.dll System.Drawing.dll System.Web.Extensions.dll
Target: Windows x64, C# 5, .NET Framework 4.8, WinExe; manifest: app.manifest.
Keep WirelessInternet.exe.config next to the desktop executable to select .NET Framework 4.8. System-DPI awareness is declared by dpiAware=true in app.manifest. The developer build copies App.config to the runtime configuration; App.config is not a separate installed source payload.
The UI uses a 96-DPI design baseline and scales to the Windows system DPI, with scrollable content when the window work area is small. Windows uniformly bitmap-scales the window across displays with different DPI, which may cause interpolation blur.
System scaling at 150% has been verified on the current test computer. Layout support for 200% is implemented but still needs validation on the target computer. After changing Windows scaling while the application is running, exit through the tray and reopen the application to use the current system configuration; Windows scaling need not be changed to 100%.
